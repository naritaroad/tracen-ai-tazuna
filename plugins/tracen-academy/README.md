# tracen-academy (Claude Code plugin)

Lets Claude read the **public** demo data of AI Hayakawa Tazuna and send non-personal feedback. It bundles two things:

| Part | File | Source |
|---|---|---|
| Skill `tracen-academy:tracen-public` | `skills/tracen-public/SKILL.md` | Generated by `cargo run -- export-skills` from `data/skills/`; the same text as `skills/tracen-public/SKILL.md` at the repository root, which stays for other agent systems. Do not edit by hand |
| MCP server `tracen-academy-public` | `.mcp.json` | Starts `tracen-api mcp-stdio` (5 tools over the public views; see `docs/engineering/upgrade-plan-1.1.md` §6) |

The data is an unofficial fan project's demo setting, never official Cygames material. Private data (conversations, cases, memories, accounts) is out of reach of the MCP server.

## Install

### From the zip

`plugins/tracen-academy.zip` (next to this folder in the repository) is the plugin packed with its root at the top level, ready to import without the marketplace:

- Claude apps with plugin upload: choose the zip in the app's plugin upload dialog. Note that the plugin starts a local program (`tracen-api`), so it only works where local MCP servers can run (Claude Code, Claude desktop), not on claude.ai in a browser.
- Claude Code, one session: unzip it anywhere and run `claude --plugin-dir <that folder>`.

Either way you still need the built `tracen-api` (step 1 below) and pick it when asked for **tracen-api executable** (step 3). The zip is generated, so do not edit it by hand: after changing anything in this folder or the skill, run `python tools/package-plugin/package_plugin.py` (`--check` tells whether it is stale).

### From the marketplace

1. In the clone: start PostgreSQL (`docker compose up -d db`), fill `.env`, and build the API: `cd backend && cargo build --release`.
2. In Claude Code:

   ```text
   /plugin marketplace add <path to the clone>
   /plugin install tracen-academy@tracen-ai-tazuna
   ```

3. When asked for **tracen-api executable**, pick `<clone>/backend/target/release/tracen-api.exe` (`tracen-api` on macOS and Linux). The server finds `.env` from the executable's folder; set `TRACEN_HOME` to the clone instead if you keep the binary elsewhere.
4. Check with `/mcp` that `tracen-academy-public` is connected, then ask, for example, "What documents does a race application need at Tracen Academy?"

Remote use: the API also serves Streamable HTTP at `/mcp` once the read-only role and the admin switch are set (`docs/engineering/development.md`, "MCP"). Add it with `claude mcp add --transport http tracen-academy-remote http://127.0.0.1:8080/mcp` instead of the stdio server.
